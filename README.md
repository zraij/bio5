# أحياء الخامس العلمي

كتاب تفاعلي لفصول كتاب علم الأحياء للصف الخامس العلمي السبعة (المنهج العراقي): شرح مصوّر ومتحرك، التعاريف والتعاليل والمقارنات والمسائل المهمة وحل أسئلة الكتاب، مختبر تفاعلي، مجسمات ثلاثية الأبعاد، وتحدّي الفرق.

- **الموقع:** https://zraij.github.io/bio5/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/bio5/admin.html (لصاحب الموقع فقط)
- **رابط التثبيت (يُرسل للأساتذة):** https://zraij.github.io/bio5/install.html — يثبّت البرنامج كتطبيق على الموبايل والشاشات التفاعلية
- **كتاب الـ PDF الأصلي:** [bio5-book.pdf](bio5-book.pdf)

محتوى الصفحة مشفّر، ولا يُفتح إلا بحساب صحيح. الحسابات محفوظة في `users.json` بشكل مشفّر، وتُدار من صفحة الإدارة. كل حساب أستاذ يُقفل على أول جهاز يدخل منه، وحساب المدير مستثنى من القفل.

- **حساب الشاشة التفاعلية:** من صفحة الإدارة ← «إضافة شاشة تفاعلية»، حساب لكل شاشة حتى ما تنقفل حسابات الأساتذة عليها
- **تنبيه للمطوّر:** بعد أي إعادة بناء لـ `index.html` تأكد أن سطر `manifest.webmanifest` وكود `__PWA` بعده موجودان، وإلا يختفي التثبيت كتطبيق
